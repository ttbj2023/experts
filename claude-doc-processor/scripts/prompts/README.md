# 数学教辅PDF处理 v3 提示词使用指南

## 概述

这是专门为数学教辅材料设计的PDF转Markdown提示词系统（v3版本），解决了以下核心问题：
- 页眉页脚自动过滤
- 注释性双栏布局处理
- 题目编号结构保留
- 数学公式精确LaTeX化
- 完全避免代码块误识别

## 核心特性

### 1. 页眉页脚过滤
自动识别并忽略：
- 页眉：书名、章节名、重复标题
- 页脚：页码、版权信息、网址
- 保留：正文核心内容

### 2. 注释性双栏处理
识别数学教辅常见的"主内容+注释"布局：
- **主栏**（较宽）：例题、讲解、练习题
- **副栏**（较窄）：注释、提示、解题思路

处理策略：将注释内容使用引用块（`> `）嵌入对应位置

示例输出：
```markdown
【例1】解下列方程

解：去分母，得
> 注意：去分母时不要漏乘常数项

整理，得 x = 3
```

### 3. 题目编号保护
完整保留：
- 题目编号：【例1】、【例2】、练习1、练习2.1
- 步骤标记：解、证明、（1）、（2）、第一步
- 章节结构：标题层级

### 4. 数学公式LaTeX化
精确转换：
- 行内公式：`$x^2 + 2x + 1 = 0$`
- 独立公式：`$$\frac{a}{b} = \frac{c}{d}$$`
- 支持语法：分数、根号、求和、积分、极限、上下标

### 5. 特殊符号处理
直接输出Unicode字符，避免代码块：
- 数学符号：∈ ∪ ∩ ⊆ ⊂ ≠ ≤ ≥ ∞
- 希腊字母：α β γ θ
- 绝对值：|x|
- 集合：{x | x > 0}
- 区间：[a, b]、(a, +∞)

## 使用方法

### 方法1：直接使用脚本（默认）
脚本已内置v3提示词，直接运行：

```bash
# 处理整个PDF
python3 scripts/process_pdf_with_glm46v_v2.py \
  --input /path/to/你的数学教材.pdf \
  --output output_dir/
```

### 方法2：自定义提示词
如果想使用其他版本的提示词或自定义：

```bash
# 编辑提示词文件
vim scripts/prompts/math_textbook_v3.txt

# 修改脚本，从文件读取提示词
```

### 方法3：快速测试（单页）
```bash

python3 scripts/process_pdf_with_glm46v_v2.py \
  --input /path/to/你的数学教材.pdf \
  --output output_test/ \
  --max-pages 3
```

## 调优建议

### 如果页眉页脚仍出现
可能原因：页眉页脚变化不明显
解决方案：
1. 在提示词中添加更多页眉页脚示例
2. 手动检查PDF，提供具体位置信息

### 如果注释未正确识别
可能原因：双栏边界不清晰
解决方案：
1. 在提示词中添加双栏识别的视觉特征
2. 调整DPI设置（默认200，可提高到250或300）

### 如果公式识别不准确
可能原因：图片压缩过度
解决方案：
1. 修改脚本中的compression参数为`none`或`low`
2. 提高DPI到250或300
3. 调整max_tokens到更高的值（如131072）

### 如果编号丢失
可能原因：模型认为编号不重要
解决方案：
1. 在提示词中强化编号的重要性
2. 添加更多编号示例

## 技术参数

### 脚本配置位置
文件：`scripts/process_pdf_with_glm46v_v2.py`
提示词位置：第223-283行

### 可调参数
```python
# 图片压缩（影响识别质量和速度）
compression="none"     # 原始质量（最慢，最准确）
compression="low"        # 低压缩（推荐，1280px）
compression="medium"     # 中压缩（1024px）
compression="high"       # 高压缩（768px）

# DPI（影响图片清晰度）
dpi=200                  # 标准清晰度（推荐）
dpi=250                  # 高清晰度
dpi=300                  # 超高清晰度

# 最大tokens（影响内容截断）
max_tokens=65536         # 64K（默认）
max_tokens=131072        # 128K（复杂页面）
```

## 故障排除

### 问题1：处理速度慢
**原因**：DPI过高或compression过低
**解决**：
```bash
# 降低DPI到150
# 使用medium压缩
compression="medium"
```

### 问题2：某些页面失败
**原因**：图片过大，API超时
**解决**：脚本会自动重试并调整压缩参数，如果仍失败：
```bash
# 手动调整compression
compression="ultra"  # 最低质量，最快速度
```

### 问题3：输出截断
**原因**：max_tokens不足
**解决**：修改脚本中的max_tokens参数
```python
max_tokens=131072  # 提高到128K
```

### 问题4：内存不足
**原因**：同时处理过多页面
**解决**：分批处理
```bash
# 先处理前50页
python3 scripts/process_pdf_with_glm46v_v2.py \
  --input book.pdf \
  --output part1/ \
  --max-pages 50

# 再处理后续页面
python3 scripts/process_pdf_with_glm46v_v2.py \
  --input book.pdf \
  --output part2/ \
  --start-page 51
```
