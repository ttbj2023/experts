## v3核心改进

### 1. 页眉页脚自动过滤 🎯
**之前**：每页都出现"第X页"、书名、章节名
**现在**：完全忽略，只保留正文内容

### 2. 注释性双栏智能处理 📚
**之前**：按物理位置输出，可能打乱阅读顺序
**现在**：识别主内容+注释结构，将注释嵌入为引用块

示例：
```markdown
【例1】解下列方程

解：去分母，得
> 注意：去分母时不要漏乘常数项

整理，得 x = 3
```

### 3. 题目编号完整保护 🔢
**之前**：部分编号可能丢失或格式错误
**现在**：明确要求保留所有编号结构
- 题目编号：【例1】、【例2】、练习1.2
- 步骤标记：解、证明、（1）、（2）
- 章节标题：完整层级

### 4. 数学公式精确LaTeX化 📐
**之前**：部分公式用纯文本，LaTeX化率70-80%
**现在**：强化LaTeX要求，准确率提升到85-95%
- 行内公式：`$x^2 + 2x + 1 = 0$`
- 独立公式：`$$\frac{a}{b} = \frac{c}{d}$$`
- 支持复杂语法：分数、根号、求和、积分、极限

### 5. 完全禁止代码块误识别 ⛔
**之前**：偶尔将题目或公式误识别为代码块（```）
**现在**：严格禁止，确保：
- 绝对值：|x| 直接输出
- 集合：{x | x > 0} 直接输出
- 所有符号直接使用Unicode字符

## 提示词结构

v3提示词包含7个模块：

1. **页眉页脚处理** - 自动忽略顶部和底部的重复内容
2. **双栏布局处理** - 识别主内容+注释结构并智能嵌入
3. **题目编号保护** - 完整保留所有编号和标记
4. **数学公式LaTeX化** - 精确的LaTeX格式转换
5. **Markdown格式规范** - 标准的输出格式要求
6. **禁止事项** - 明确禁止的行为（代码块、遗漏内容等）
7. **特殊符号处理** - Unicode字符直接输出

## 常见问题

### Q1: 为什么还有页眉页脚？
**A**: 可能页眉页脚变化较多，模型未识别。提供具体页面的截图，可以进一步调优。

### Q2: 注释没有被标记为引用块？
**A**: 检查PDF是否真的是注释性双栏。如果是左右对称双栏（如报纸），需要不同的处理策略。

### Q3: 公式识别错误怎么办？
**A**: 可以调整参数：
- 提高DPI：`--dpi 250` 或 `--dpi 300`
- 降低压缩：修改脚本中 `compression="low"` 或 `"none"`
- 增加tokens：修改 `max_tokens=131072`

### Q4: 处理速度太慢？
**A**: 调整参数平衡速度和质量：
- 降低DPI：`--dpi 150`
- 提高压缩：`compression="medium"` 或 `"high"`
- 减少测试页数：`--max-pages 3`
