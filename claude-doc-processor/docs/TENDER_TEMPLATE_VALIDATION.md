## 🔬 详细验证

### 1. 字体验证

#### 正文样式（CSS）

```css
body {
    font-family: '宋体', 'Times New Roman', serif;
    font-size: 12pt;  /* 小四号 */
    color: #24292E;   /* 正文深色 */
}
```

**验证**：
- ✅ 中文字体：宋体
- ✅ 西文字体：Times New Roman
- ✅ 字号：12pt（小四号）
- ✅ 符合GB/T 9704-2012要求

#### 标题样式（CSS）

```css
h1 {
    font-family: '黑体', '宋体', sans-serif;
    font-size: 16pt;    /* 三号 */
    font-weight: bold;
    color: #000000;     /* 纯黑 */
    text-align: center;
}

h2 {
    font-family: '黑体', '宋体', sans-serif;
    font-size: 15pt;    /* 小三号 */
    font-weight: bold;
    color: #000000;
    text-align: left;
    margin-top: 14pt;
    margin-bottom: 10pt;
}
```

**验证**：
- ✅ 标题字体：黑体
- ✅ 一级标题：16pt居中加粗
- ✅ 二级标题：15pt左对齐加粗
- ✅ 颜色：纯黑#000000

### 2. 段落格式验证

#### 段落样式（CSS）

```css
p {
    margin-top: 0pt;
    margin-bottom: 0pt;
    text-indent: 2em;    /* 首行缩进2字符 */
    text-align: justify; /* 两端对齐 */
}
```

**验证**：
- ✅ 段前间距：0pt
- ✅ 段后间距：0pt
- ✅ 首行缩进：2em（2字符）
- ✅ 对齐方式：justify（两端对齐）
- ✅ 行距：1.5倍

**标书特殊性**：
标书规范要求段前段后均为0pt，依靠首行缩进来区分段落。

### 3. 页面布局验证

#### @page样式（CSS）

```css
@page {
    size: A4;
    margin: 2.2cm 2.2cm 2.2cm 2.7cm;  /* 上 右 下 左 */
}
```

**验证**：
- ✅ 纸张：A4
- ✅ 上边距：2.2cm
- ✅ 右边距：2.2cm
- ✅ 下边距：2.2cm
- ✅ 左边距：2.7cm（装订侧）

**标书特殊性**：
左侧边距设置为2.7cm（比其他边多0.5cm），这是为了满足装订要求。标书通常需要左侧装订成册，因此需要预留更大的装订边距。

### 4. 表格样式验证

#### 表格单元格样式（CSS）

```css
td {
    border: 0.75pt solid #000000;
    padding: 4pt;
    text-align: center;
    font-size: 10.5pt;  /* 五号 */
}

th {
    border: 0.75pt solid #000000;
    padding: 4pt;
    text-align: center;
    font-weight: bold;
    border-bottom: 1.5pt solid #000000;
}
```

#### 表题样式（CSS）

```css
.table-caption {
    text-align: center;
    font-size: 16pt;    /* 三号 */
    font-weight: bold;
    color: #000000;
}
```

**验证**：
- ✅ 边框宽度：0.75pt（0.75磅）
- ✅ 边框颜色：纯黑#000000
- ✅ 内容字号：10.5pt（五号）
- ✅ 表题字号：16pt（三号）
- ✅ 表题对齐：居中
- ✅ 表头加粗：是
- ✅ 表头背景：白色#FFFFFF（无背景色）
- ✅ 单元格内边距：4pt

**标书特殊性**：
1. 表头使用白色背景，不使用灰色或其他颜色
2. 边框严格按照0.75磅标准
3. 表题字号较大（三号），与正文形成对比
