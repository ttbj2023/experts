## 标准概述

### GB/T 9704-2012 简介

《党政机关公文格式》是中华人民共和国国家标准，由国家质量监督检验检疫总局、国家标准化管理委员会发布，于**2012年7月1日**起正式实施。

**核心目的**：
- 统一党政机关公文格式
- 推进公文处理工作科学化、制度化、规范化
- 提高公文处理效率和质量

**适用范围**：
- 各级党政机关制发的公文
- 其他机关和单位的公文可参照执行

### 3. 行距和排版规范

#### 正文排版
```yaml
行距: 固定值 28磅（约相当于单倍行距）
每页行数: 22行
每行字数: 28个汉字
首行缩进: 2字符
对齐方式: 两端对齐
段前段后: 0磅
```

**重要提示**：
- 行距必须是**固定值28磅**，不是"单倍行距"
- 每页正好**22行**，每行**28字**
- 所有标题和正文都遵循相同行距

#### 标题行距
```yaml
公文标题: 固定值 35磅
其他标题: 固定值 28磅（与正文相同）
```

### 4. 标题层级规范

#### 层级序数规则

**第一层**：`一、`、`二、`、`三、`、`四、`
- 字体：3号黑体
- 加粗：否
- 用途：章标题

**第二层**：`（一）`、`（二）`、`（三）`、`（四）`
- 字体：3号楷体_GB2312
- 加粗：是
- 用途：节标题

**第三层**：`1.`、`2.`、`3.`、`4.`
- 字体：3号仿宋_GB2312
- 加粗：是
- 注意：数字后是**圆点**，不是顿号
- 用途：目标题

**第四层**：`（1）`、`（2）`、`（3）`、`（4）`
- 字体：3号仿宋_GB2312
- 加粗：否
- 用途：细目标题

#### 标题示例

```
一、总体要求

（一）指导思想

1. 加强组织领导。
   要建立健全领导机制...

2. 完善制度建设。
   要制定相关制度...

（1）明确责任分工。
（2）强化监督考核。
```

**示例**：

#### 版记位置和结构

```
┌──────────────────────────────────┐
│ （公文主体内容结束）              │
├══════════════════════════════════┤ ← 粗线（0.35mm）
│ 抄送：××局，××委员会。           │
│ ────────────────────────────────  │ ← 细线（0.25mm）
│ 印发机关：××办公厅               │

├══════════════════════════════════┤ ← 粗线（0.35mm）

```

#### 分隔线规范

| 分隔线 | 高度 | 用途 |
|--------|------|------|
| **首条分隔线** | 0.35mm（粗线） | 版记第一个要素之上 |
| **中间分隔线** | 0.25mm（细线） | 抄送机关和印发机关之间 |
| **末条分隔线** | 0.35mm（粗线） | 版记最后一行，与版心下边缘重合 |

## 常见问题

### Q1: 为什么行距要设置固定值28磅？

**A**: 这是国家标准的硬性要求。

**原因**：
- 国家标准规定每页**22行**、每行**28字**
- 使用3号仿宋字时，只有设置固定值28磅才能达到这个要求
- 如果使用"单倍行距"，每页只能排21行

**设置方法**：
- Word：右键→段落→行距→固定值→28磅

---

### Q2: 二级标题为什么要用楷体_GB2312？

**A**: 这是国家标准的规定。

**层级标题字体对照**：
- 一级标题：黑体（不加粗）
- 二级标题：楷体_GB2312（加粗）
- 三级标题：仿宋_GB2312（加粗）
- 四级标题：仿宋_GB2312（不加粗）

---

### Q3: 如何输入六角括号「„‟」？

**A**:

**方法1：输入法**
- 搜狗拼音/微软拼音：输入"六角括号"或"ljkh"
- 会在候选词中显示`„‟`

**方法2：复制粘贴**
```
„‟
```

**方法3：Word插入**
- 插入→符号→更多符号
- 字体：普通文本
- 子集：中文标点符号
- 找到`„‟`插入

---

### Q4: 仿宋_GB2312和仿宋有什么区别？

**A**:

| 字体 | 区别 | 推荐度 |
|------|------|--------|
| **仿宋_GB2312** | 国家标准字体，字符集更全 | ⭐⭐⭐⭐⭐ |
| **仿宋** | Windows系统字体，字符集较少 | ⭐⭐⭐ |

**建议**：
- 公文应使用**仿宋_GB2312**
- 如果系统没有，可使用仿宋代替
- 但正式印刷时应使用仿宋_GB2312

---

### Q5: 标题层级序数后应该用什么标点？

**A**:

| 层级 | 序数 | 标点 | 示例 |
|------|------|------|------|
| **第一层** | 一、 | 顿号 | 一、总体要求 |
| **第二层** | （一） | 无标点 | （一）指导思想 |
| **第三层** | 1. | 圆点（英文句点） | 1. 加强组织 |
| **第四层** | （1） | 无标点 | （1）明确分工 |

**特别注意**：
- 第三层标题`1.`后是**圆点**，不是顿号
- 第四层标题`（1）`后无标点

---

## 最佳实践

### 1. 写作规范

✅ **推荐做法**：
- 严格按照层级序数使用标题
- 一级标题不超过5个
- 每个层级有2个以上同级标题才使用
- 附件序号用阿拉伯数字
- 附件名称后不加标点

❌ **避免**：
- 跳级使用标题（如直接从"一、"跳到"1."）
- 单独使用一个同级标题
- 附件序号使用中文数字
- 混用不同的标题序数格式

## 附录

### A. 文种说明

党政机关公文的15种文种：

1. **决议**：适用于会议讨论通过的重大决策事项
2. **决定**：适用于重要事项作出决策和部署
3. **命令（令）**：适用于公布行政法规和规章
4. **公报**：适用于公布重要决定或者重大事项
5. **公告**：适用于向国内外宣布重要事项或者法定事项
6. **通告**：适用于在一定范围内公布应当遵守或者周知的事项
7. **意见**：适用于对重要问题提出见解和处理办法
8. **通知**：适用于发布、传达要求下级机关执行的事项
9. **通报**：适用于表彰先进、批评错误、传达重要精神
10. **报告**：适用于向上级机关汇报工作、反映情况
11. **请示**：适用于向上级机关请求指示、批准
12. **批复**：适用于答复下级机关请示事项
13. **议案**：适用于各级人民政府按法律程序向同级人民代表大会提请审议事项
14. **函**：适用于不相隶属机关之间商洽工作、询问和答复问题
15. **纪要**：适用于记载会议主要情况和议定事项
