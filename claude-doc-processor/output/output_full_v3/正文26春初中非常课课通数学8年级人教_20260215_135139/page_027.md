# 24.4 数据的分组

## 目标直通车
1. 了解数据分组的意义,更细致地分析数据的离散程度.
2. 会求数据的组内离差平方和与组间离差平方和,并能应用于生活实际.

### 知识点1 组内离差平方和
1. 把 n 个数据分为两组,前 m(m<n)个数据为一组,后(n−m)个数据为一组,它们的平均数分别记为 $\bar{x}_1$ 和 $\bar{x}_2$,两组的离差平方和分别记为 $d_1^2$ 和 $d_2^2$,则 $d_1^2 + d_2^2$ 称为组内离差平方和.
> ! 提示 分组方法不同,组内离差平方和的大小也不同,这正是为分析如何分组,才能使数据的组内离散程度最小提供了方法.

【例1】已知数据 7,9,11,10,9,将数据分为前2个数一组与后3个数一组.求组内离差平方和.
解:将数据从小到大排列为7,9,9,10,11.第一组:7,9;第二组:9,10,11.$\bar{x}_1 = \frac{7+9}{2} = 8$, $\bar{x}_2 = \frac{9+10+11}{3}=10$.∴ $d_1^2=(7-8)^2+(9-8)^2=2,d_2^2=(9-10)^2+(10-10)^2+(11-10)^2=2. ∴ d_1^2 + d_2^2 = 2+2=4$,即组内离差平方和为4.
> 分析 先将数据从小到大排列,再按要求分组,继而可求组内离差平方和.
> 点拨 通常情况下,按大小排序是分组的前提.

### 知识点2 组间离差平方和
1. 组间离差平方和的定义:把数据分为两组,两组数据的平均数关于总体数据平均数的离差平方和,称为组间离差平方和.
2. 组间离差平方和的计算公式: $d_{12}^2 = m(\bar{x}_1 - \bar{x})^2 + (n-m)(\bar{x}_2 - \bar{x})^2$.

【例2】已知数据 2,7,4,5,12.将数据的前两个数一组,后三个数一组.求两组的组间离差平方和.
解:先排序,后分组,再求两组数据的平均数,最后利用公式求组间离差平方和.
数据从小到大排序为2,4,5,7,12.
第一组:2,4;第二组:5,7,12.
∴ $\bar{x}_1 = \frac{2+4}{2}=3$, $\bar{x}_2 = \frac{5+7+12}{3}=8$, $\bar{x} = \frac{2+7+4+5+12}{5}=6$.
∴ $d_{12}^2=2×(3-6)^2 + 3×(8-6)^2=18+12=30.$
> 点拨 分组方法不同,组间离差平方和的大小也不尽相同.如本题,若按前1个后4个分组,即第一组:2;第二组:4,5,7,12,则 $\bar{x}_1 = 2$, $\bar{x}_2 = \frac{4+5+7+12}{4}=7$.此时 $d_{12}^2=1×(2-6)^2 + 4×(7-6)^2=16+4=20<30.$
