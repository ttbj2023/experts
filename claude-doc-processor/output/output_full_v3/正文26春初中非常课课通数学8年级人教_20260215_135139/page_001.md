### 知识点1 平均数[重点]
1. 一般地，有 n 个数据 \(x_1, x_2, \dots, x_n\)，我们把 \(\frac{1}{n}(x_1 + x_2 + \dots + x_n)\) 叫作这 n 个数据的平均数，记作 \(\overline{x}\)，即 \(\overline{x} = \frac{1}{n}(x_1 + x_2 + \dots + x_n)\)。  
> !提示 平均数的缺点是容易受个别特殊值的影响，所以有时不能代表数据的平均水平。  
> 零拓展 一般地，我们把 n 个数 \(x_1, x_2, \dots, x_n\) 的和与 n 的比叫作这 n 个数的算术平均数，简称平均数。

2. 平均数的大小与每个数据都有关系，它反映了一组数据取值的平均水平。如果需要了解一组数据的平均水平，那么可计算这组数据的平均数。  
3. 当一组数据较大，并且这些数据都在某一常数 a 附近上下波动时，一般选用“新数据法”计算；取该常数 a 为标准数，算出各数与标准数的差的平均数，然后加上 a 即可得到这组数据的平均数。
