解：当$x \geq 7$时，原数据按从小到大的顺序排列为$5,7,7,x$，其中位数为$\frac{7+7}{2}=7$。
∵中位数与平均数相等，
∴$\frac{5+7+7+x}{4}=7$，解得$x=9$。

当$x \leq 5$时，原数据按从小到大的顺序排列为$x,5,7,7$，其中位数为$\frac{5+7}{2}=6$。
∵中位数与平均数相等，
∴$\frac{5+7+7+x}{4}=6$，解得$x=5$。

当$5 < x < 7$时，原数据按从小到大的顺序排列为$5,x,7,7$，其中位数为$\frac{x+7}{2}$。
∵中位数与平均数相等，
∴$\frac{5+7+7+x}{4}=\frac{x+7}{2}$，解得$x=5$(不合题意，舍去)。

综上所述，当$x=5$时，中位数为6；当$x=9$时，中位数为7。
> 非常点评
> 本题实际上考查了中位数的取值，要注意当数据的大小未知时，就应对未知数据进行分类讨论从而确定排列顺序，进而确定中位数。

# 统计思想在实际生活中的应用

统计学是一门与数据打交道的学科，研究如何收集、整理、计算和分析数据，然后从中找到一些规律。运用统计知识，解决实际生活中涉及有关数据的问题，就是统计的思想方法的应用。

例6 某校数学社团成员采用简单随机抽样的方法，抽取了本校八年级50名学生，对他们一周内平均每天的睡眠时间进行了调查，将数据整理后绘制成下表：
| 平均每天的睡眠时间$t/$小时 | 频数 |
|---------------------------|------|
| $5 \leq t < 6$             | 1    |
| $6 \leq t < 7$             | 5    |
| $7 \leq t < 8$             | $m$  |
| $8 \leq t < 9$             | 24   |
| $t \geq 9$                 | $n$  |

该样本中学生平均每天的睡眠时间达9小时及以上的百分比达到了22%。
(1) 求表格中$n$的值；
(2) 该校八年级共有400名学生，估计其中平均每天的睡眠时间$t($小时)$在$7 \leq t < 8$这个范围内的人数。

解析：(1) 根据频率=频数/总体数量求解可得。(2) 先根据频数的和是50及$n$的值求出$m$的值，再用总人数乘样本中平均每天的睡眠时间$t($小时)$在$7 \leq t < 8$这个范围内的人数所占比例即可求得。

解：(1) $n=50 \times 22\% = 11$。
(2) ∵$m=50-1-5-24-11=9$，
∴估计该校八年级平均每天的睡眠时间$t($小时)$在$7 \leq t < 8$这个范围内的人数是$400 \times \frac{9}{50}=72$。

> 非常点评
> 本题主要考查了用样本估计总体及频数分布表，解题的关键是掌握频率=频数/总体数量。
