# 年薪特征  
解析：(1)用加权平均数公式求平均年薪。(2)先画图，再根据箱线图的特点分析年薪波动情况、离散程度等。  
解：(1)$\bar{x}_{甲}=\frac{100\times1+50\times2+18\times4+8\times20}{1+2+4+20}=\frac{432}{27}=16$（万元）。  
$\bar{x}_{乙}=\frac{30\times1+20\times2+18\times4+14.5\times20}{1+2+4+20}=\frac{432}{27}=16$（万元）。  
(2)甲企业年薪数据:最小值=8,最大值=100,Q₂的值为第14个数,即Q₂=8;Q₁的值为前13个数的中位数,即第7个数,则Q₁=8;Q₃的值为后13个数的中位数,即第21个数,则Q₃=18。  
乙企业年薪数据:最小值为14.5,最大值为30;与甲数据的求法相同,可得Q₁=14.5,Q₂=14.5,Q₃=18。  
画箱线图如图所示。

## 误区警示牌  
- 易错点：不会确定下四分位数和上四分位数  
> 例 求下列两组数据的中位数与下四分位数.  
(1) 1,3,5,7,9;  
(2) 2,4,6,8,10,12.  

正确解答：(1)$Q_2=5,Q_1=\frac{1+3}{2}=2$.  
(2)$Q_2=\frac{6+8}{2}=7,Q_1=4$.  

> 误区分析 本题易作如下误解:(1)Q₂=5,Q₁=3;(2)Q₃=7,Q₁=3.发生上述错误的原因是对求第一、三四分位数的方法不熟悉。(1)中共有5个数，中位数(即Q₂)为5,此时求下四分位数时,应求中位数左侧两个数的平均数(不包括中位数);(2)中共有6个数,此时中位数为6与8的平均数,第一四分位数应为2.4,6的中位数(特别注意:包括6).
