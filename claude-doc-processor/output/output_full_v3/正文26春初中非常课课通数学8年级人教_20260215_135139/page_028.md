### 典例展示厅
**题型** 计算组内离差平方和解实际问题  

**典例** 2024年四个城市人均GDP（单位：万元）取整数，从小到大依次为A市:11,B市:14,C市:20,D市:23.  
(1) 求四个城市人均GDP数据的平均数；  
(2) 填写下表：  

| 分组 | 第1组 | 第2组 | 组内离差平方和 |
| --- | --- | --- | --- |
| 第1个间隔 |  |  |  |
| 第2个间隔 |  |  |  |
| 第3个间隔 |  |  |  |

(3) 按组内离差平方和最小的原则将四个城市分为两组.  
解析:(1) 根据平均数公式求四个城市人均GDP数据的平均数.(2) 利用离差平方和公式计算填表. (3) 视图表结果确定.  

解:(1) $x = \frac{11+14+20+23}{4} = 17.$  

(2) 把数据按从小到大排列为11,14,20,23.  
> 按第1个间隔分组，第1组:11; 第2组:14,20,23. 此时 $\bar{x_1}=11$, $d_1^2=0$, $\bar{x_2}=19$, $d_2^2=42$. ∴ $d_1^2+d_2^2=42$.  
> 按第2个间隔分组，第1组:11,14; 第2组:20,23. 此时 $\bar{x_1}=12.5$, $d_1^2=4.5$, $\bar{x_2}=21.5$, $d_2^2=4.5$. ∴ $d_1^2+d_2^2=9$.  
> 按第3个间隔分组，第1组:11,14,20; 第2组:23. 此时 $\bar{x_1}=15$, $d_1^2=42$, $\bar{x_2}=23$, $d_2^2=0$. ∴ $d_1^2+d_2^2=42$.  
将以上数据对应填入表格.  

(3) 按组内离差平方和最小的原则将四个城市分为两组如下:(A市,B市)和(C市,D市).  

> 非常点评 从上面的分组可看出，A市与B市的人均GDP相差较小,而C市与D市的人均GDP也相差较小,因此,这种分组方法是将相对靠近的数据分在同一个组.  


**误区警示牌**  
- 易错点 不将数据排序造成错误分组  
  例 将数据4,2,6,5,3按前三个数一组,后二个数一组,求组内离差平方和.  
  正确解答:将数据从小到大排列如下:2,3,4,5,6. 按要求分组:第1组:2,3,4; 第2组:5,6. ∴ $\bar{x_1}=\frac{2+3+4}{3}=3$, $d_1^2=(2-3)^2+(3-3)^2+(4-3)^2=2$, $x_2=\frac{5+6}{2}=5.5$, $d_2^2=(5-5.5)^2+(6-5.5)^2=0.5$. ∴ $d_1^2+d_2^2=2+0.5=2.5$.  
  误区分析 若不排序分组为第1组:4,2,6; 第2组:5,3,则计算结果大大高于2.5,读者可以一试.
