### 典型1 方差的计算方法
**典例7（2024·江阴模拟）**已知一组数据为7,2,5,x,8，它们的平均数是5，则这组数据的方差为（）  
A.3 B.4.5 C.5.2 D.6  

解析：因为一组数据7,2,5,x,8的平均数是5，所以\(5 = \frac{1}{5} \times (7 + 2 + 5 + x + 8)\)。所以\(x = 3\)。所以  
\(s^2 = \frac{1}{5} \times [(7 - 5)^2 + (2 - 5)^2 + (5 - 5)^2 + (3 - 5)^2 + (8 - 5)^2] = 5.2.\)  

答案：C.  

**非常点评**
方差的计算公式\(s^2 = \frac{1}{n}[(x_1 - \overline{x})^2 + (x_2 - \overline{x})^2 + \dots + (x_n - \overline{x})^2]\)中的\(\overline{x}\)是平均数，因此，求一组数据的方差，必须已知平均数和各个数据。若本题给出\(x\)的值，但平均数未知，则需要先求平均数，而本题只需要先求\(x\)的值，方差就能直接用公式计算了。

### 类型2 联合运用“三数”与方差解决问题
**典例8（2024·金湖模拟）**某校组织学生参加卫生知识竞赛，为了解竞赛情况，从两个年级各抽取10名学生的成绩(满分为100分)。  
收集数据：  
七年级：90,95,95,80,85,90,80,90,90,85,100；  
八年级：85,85,95,80,95,90,90,90,100,90。  

分析数据：

|            | 平均数 | 中位数 | 众 数 | 方 差 |
|------------|--------|--------|-------|-------|
| 七年级     | 89     | \(m\)   | 90    | 39    |
|---|---|---|---|---|
| 八年级     | \(n\)  | 90      | \(p\)  | \(q\) |

根据以上信息解答下列问题：  
（1）\(m = \_\_\_\_，n = \_\_\_\_，p = \_\_\_\_.\)  
（2）从方差的角度看，\(\_\_\_\_\)学生的成绩更稳定(填“七年级”或“八年级”).  
（3）通过数据分析，你认为哪个年级学生的成绩更好？请说明理由.  

解析：（1）七年级10名学生成绩数据从小到大排列，处在中间位置的两个数都是90，因此\(m = 90\); 八年级学生成绩数据的平均数为\(\frac{80 + 85 \times 2 + 90 \times 4 + 95 \times 2 + 100}{10} = 90\)，即\(n = 90\); 八年级学生成绩数据出现次数最多的是90，共出现4次，因此众数是90，即\(p = 90.\)（2）八年级学生成绩数据的方差\(q = \frac{1}{10} \times [(80 - 90)^2 + (85 - 90)^2 \times 2 + (90 - 90)^2 \times 4 + (95 - 90)^2 \times 2 + (100 - 90)^2] = 30\)，即\(q = 30.\) 因为30 < 39，所以八年级学生的成绩更稳定.（3）根据平均数和方差的大小进行比较即可.  

解：（1）90；90；90.  
（2）八年级.  
（3）八年级学生的成绩更好.  
理由：∵两个年级学生成绩的中位数和众数相同，八年级学生成绩的平均数比七年级高，方差比七年级小，  
∴八年级学生的成绩更好.  

**非常点评**
本题考查了平均数、中位数、众数等“三数”以及方差的计算方法，概括了本章的所有基础知识. 另外，第（3）题是开放题，回答时应从“三数”与方差的角度加以阐述，而两组数据的中位数与众数对应相等，因此，可侧重从平均数与方差方面进行比较. 特别注意：方差越大，数据的波动越大，数据的稳定性越差，一般情况下，数据应追求高稳定性.
