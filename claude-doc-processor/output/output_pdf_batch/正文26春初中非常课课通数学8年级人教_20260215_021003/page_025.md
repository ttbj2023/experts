# 非常课课通 数学(RJ版)八年级下

年薪特征.

解析：(1) 用加权平均数公式求平均年薪.(2) 先画图,再根据箱线图的特点分析年薪波动情况、离散程度等.

解:(1) \(\bar{x}_{甲} = \frac{100×1 + 50×2 + 18×4 + 8×20}{1+2+4+20} = \frac{432}{27} = 16\)(万元).

\(\bar{x}_{乙} = \frac{30×1 + 20×2 + 18×4 + 14.5×20}{1+2+4+20} = \frac{432}{27} = 16\)(万元).

(2) 甲企业年薪数据:最小值=8,最大值=100,Q₂的值为第14个数,即Q₂=8;Q₁的值为前13个数的中位数,即第7个数,则Q₁=8;Q₃的值为后13个数的中位数,即第21个数,则Q₃=18.

乙企业年薪数据:最小值为14.5,最大值为30;与甲数据的求法相同,可得Q₁=14.5,Q₂=14.5,Q₃=18.

画箱线图如图所示.

由箱线图知:① 甲企业数据波动大,而乙企业数据波动小;② 两组数据的最小值、第一四分位数、第二四分位数三个数据均分别相等,导致箱体下方无“须线”,表明前面的数据频数很大;③ 甲企业箱体上方的“须线”很长,表明最大数据离散严重(即个别人员年薪特别高),而乙企业箱体上方的“须线”相对较短,最大数据离散不太严重,表明年薪差距不太大(合理即可).

  <dt>误区分析</dt>
  <p>本题易作如下误解:(1) Q₂=5,Q₁=3;(2) Q₂=\(\frac{6+8}{2}=7\),Q₁=\(\frac{2+4}{2}=3\).发生上述错误的原因是对求第一、三四分位数的方法不熟悉.(1)中共有5个数,中位数(即Q₂)为5,此时求下四分位数时,应求中位数左侧两个数的平均数(不包括中位数);(2)中共有6个数,此时中位数应为6与8的平均数,第一四分位数应为2,4,6的中位数(特别注意:包括6).</p>
