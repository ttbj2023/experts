## 知识结构图示
- 平均数  
  - 算术平均数：一般地，对于\(n\)个数\(x_1, x_2, \cdots, x_n\)，我们把\(\frac{1}{n}(x_1 + x_2 + \cdots + x_n)\)叫作这\(n\)个数的算术平均数，简称平均数，记作\(\bar{x}\)，即\(\bar{x} = \frac{1}{n}(x_1 + x_2 + \cdots + x_n)\)  
  - 加权平均数：① 若\(n\)个数\(x_1, x_2, \cdots, x_n\)的权分别是\(w_1, w_2, \cdots, w_n\)，则\(\frac{x_1 w_1 + x_2 w_2 + \cdots + x_n w_n}{w_1 + w_2 + \cdots + w_n}\)叫作这\(n\)个数的加权平均数；  
    ② 在求\(n\)个数的平均数时，如果\(x_1\)出现了\(f_1\)次，\(x_2\)出现了\(f_2\)次，…，\(x_k\)出现了\(f_k\)次（这里\(f_1 + f_2 + \cdots + f_k = n\)），那么这\(n\)个数的平均数\(\bar{x} = \frac{x_1 f_1 + x_2 f_2 + \cdots + x_k f_k}{n}\)也叫作\(x_1, x_2, \cdots, x_k\)这\(k\)个数的加权平均数。其中\(f_1, f_2, \cdots, f_k\)分别叫作\(x_1, x_2, \cdots, x_k\)的权  
- 中位数：将一组数据按照从小到大(或从大到小)的顺序排列，若数据的个数是奇数，则称处于中间位置的数为这组数据的中位数；若数据的个数是偶数，则称中间两个数据的平均数为这组数据的中位数  
- 众数：一组数据中出现次数最多的数据称为这组数据的众数  
- 离差平方和与方差：设有\(n\)个数据\(x_1, x_2, \cdots, x_n\)，它们的平均数为\(\bar{x}\)，则这组数据的离差平方和为\(d^2 = (x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2\)。这组数据的方差为\(s^2 = \frac{1}{n}[(x_1 - \bar{x})^2 + (x_2 - \bar{x})^2 + \cdots + (x_n - \bar{x})^2]\)  
- 用样本估计总体：用样本平均数估计总体平均数；用样本方差估计总体方差  
- 四分位数：将一组数据从小到大排列，数据的中位数叫作第二四分位数；第二四分位左侧数据的中位数叫作第一四分位数（或下四分位数）；第二四分右侧数据的中位数叫作第三四分位数（或上四分位数）  
- 数据的分组原则：组内离差平方和最小
