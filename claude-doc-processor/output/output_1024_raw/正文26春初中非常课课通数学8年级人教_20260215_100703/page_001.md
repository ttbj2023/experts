## 知识百宝箱
### 知识点1 平均数 [重点]
1. 一般地，有 n 个数据 $x_1, x_2, \cdots, x_n$，我们把 $\bar{x} = \frac{1}{n}(x_1 + x_2 + \cdots + x_n)$ 叫作这 n 个数据的平均数，记作 $\bar{x}$，即 $\bar{x}= \frac{(x_{1}+x_{2}+\cdots+x_{n})}{n}$。
2. 平均数的大小与每个数据有关，它反映了一组数据取值的平均水平。如果需要了解一组数据的平均水平，那么可以计算这组数据的平均数。
3. 当一组数据较大，并且这些数据在某一常数 a 附近上下波动时，一般选用“新数据法”计算平均数。即该数组中每个数据与标准数的差的平均值，然后加上 a 即可得到这组数据的平均数。

**示例** 数据1,0,3,4,4的平均数是 ( )
A. 4
B. 3
C. 2.5
D. 2

解析：根据平均数的定义“平均数是指一组数据中所有数据之和除以数据的个数”进行计算，即 $(1 + 0 + 3 + 4 + 4) \div 5 = 2$。

### 知识点2 加权平均数 [重点]
1. 一般地，若 n 个数 $x_1, x_2, \cdots, x_n$ 的权分别是 $w_1, w_2, \cdots, w_n$，则 $\bar{x} = \frac{w_1 x_1 + w_2 x_2 + \cdots + w_n x_n}{w_1 + w_2 + \cdots + w_n}$ 叫作这 n 个数的加权平均数。在求 n 个数的平均数时，如果在 n 个数中 $x_i$ 出现 $f_i$ 次；出现 $f_j$ 次；……则 $\bar{x} = \frac{w_1 x_1 + w_2 x_2 + \cdots + w_n x_n}{w_1 + w_2 + \cdots + w_n}$。
