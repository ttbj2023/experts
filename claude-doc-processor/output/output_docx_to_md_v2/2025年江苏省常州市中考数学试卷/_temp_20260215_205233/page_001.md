5．(2分) 如图，在Rt△ABC中，∠A=90°，AB=3，AC=4，则sinB的值是（ ）  
   > （注释：在直角三角形中，sinB = 对边/斜边 = AC / BC，先求BC = √(AB² + AC²) = 5）

   - 所以sinB = AC/BC = 4/5
