## 🆚 核心差异：V2 vs Universal

### 1. 提示词设计哲学

#### **V2 版本**（教辅书特化）
```python
## 二、双栏/多栏布局处理
文档可能采用"主内容 + 辅助内容"的多栏布局：
- 主栏（较宽）：正文、例题、主要内容等
- 副栏（较窄）：注释、提示、说明、批注等辅助内容

处理方式：
1. 识别主栏和副栏的内容关系
2. 将辅助内容嵌入到主内容的对应位置
3. 使用引用块语法（在行首添加 > 符号）标记注释/批注内容
```

**特点**：
- ✅ 假设固定布局（主宽副窄）
- ✅ 硬编码处理方式（副栏转引用块）
- ❌ 不适合等宽双栏（学术论文）
- ❌ 不适合杂志、技术文档

#### **Universal 版本**（通用智能）
```python
## 二、布局智能识别与处理（核心）

请根据页面的实际布局特征，选择最合适的处理方式：

### 类型1：单栏布局（图书、报告、标准文档）
### 类型2：等宽双栏布局（学术论文、期刊、杂志）
### 类型3：不等宽双栏/多栏布局（教辅书、技术文档）
### 类型4：图文混排布局（杂志、画报、宣传册）
### 类型5：多栏不规则布局（报纸、复杂版式）

**布局判断依据**：
1. 比较各栏的宽度比例
2. 观察内容的主次关系
3. 检查是否有对称布局特征
4. 注意图文的位置关系
5. 确认内容是否跨栏连续
```

**特点**：
- ✅ 让AI自动识别布局类型
- ✅ 针对不同类型提供不同处理方案
- ✅ 灵活适应各种文档
- ✅ 保留所有内容选项

### 3. 双栏处理示例

#### 场景1：IEEE 论文（等宽双栏）

**原始布局**：
```
┌─────────────────┬─────────────────┐
│ Abstract        │                 │
│ Introduction... │  [等宽]         │
│                 │                 │
└─────────────────┴─────────────────┘
```

**V2 输出**：
```markdown
## 例题：Abstract

> The paper presents...

> Introduction...
```
❌ 强行转为引用块，破坏结构

**Universal 输出**：
```markdown
## 左栏内容

Abstract

The paper presents...

## 右栏内容

Introduction...
```
✅ 保持双栏结构，清晰明了

---

#### 场景2：数学教辅书（主副栏）

**原始布局**：
```
┌──────────────────────┬──────┐
│ 例1：求解方程         │ 注释 │
│ x² + 2x + 1 = 0      │ 提示 │
└──────────────────────┴──────┘
```

**V2 输出**：
```markdown
## 例1：求解方程

x² + 2x + 1 = 0

> **提示**：这是一个完全平方式
```
✅ 完美支持

**Universal 输出**：
```markdown
## 例1：求解方程

x² + 2x + 1 = 0

> **提示**：这是一个完全平方式
```
✅ 同样完美（识别为类型3）

---

#### 场景3：技术杂志（图文混排）

**原始布局**：
```
┌───────────┬──────────┐
│ 标题      │ [大图]  │
│ 正文...  │          │
│ 正文...  │ 正文... │
└───────────┴──────────┘
```

**V2 输出**：
```markdown
## 标题

正文...

> [图片]
> 正文...
```
❌ 图片和文字关系混乱

**Universal 输出**：
```markdown
## 标题

正文...

<!-- IMAGE_PLACEHOLDER
type: 插图
description: ...
-->

正文...
```
✅ 图文位置正确，占位符详细

## 📖 使用建议

### 选择 V2 版本，当你处理：
- ✅ 数学教辅书
- ✅ 物理习题集
- ✅ 化学参考书
- ✅ 明确是"主内容+侧边注释"的文档

**优势**：
- 提示词更专注
- 可能为注释内容提供更好的处理
- 减少AI判断负担

**劣势**：
- 不适用于其他文档类型
- 可能破坏标准双栏结构

---

### 选择 Universal 版本，当你处理：
- ✅ **学术论文**（IEEE/ACM双栏）
- ✅ **技术图书**（各种格式）
- ✅ **杂志期刊**（图文混排）
- ✅ **报告白皮书**（标准文档）
- ✅ **技术手册**（复杂布局）
- ✅ **不确定文档类型**时 ⭐

**优势**：
- 适应性最强
- 自动识别布局
- 覆盖几乎所有场景

**劣势**：
- 提示词稍长（增加token消耗，约+500 tokens）
- 需要AI进行布局判断
