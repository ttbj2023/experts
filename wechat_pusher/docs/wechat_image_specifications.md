# 微信公众号图片规范指南（2025修正版）

## 📸 核心要点（重要）

### ✅ 正确做法

1. **生成高分辨率图片**（Seedream 4.5范围）
   - 最小: 2560×1440
   - 推荐: 3840×2160 或更高
   - 格式: PNG（质量最优）

2. **直接上传原图**
   - ✅ 微信会自动压缩到合适尺寸
   - ✅ 高分辨率原图压缩后质量更好
   - ❌ 不要预先缩小

3. **微信自动处理规则**
   - 宽度超过 **1080px** 会自动压缩到1080px
   - PNG格式受压缩影响最小
   - 单张图片像素乘积不超过600万

## 📋 微信公众号图片显示规范

### 1. 封面图（头条）

**显示比例**: `2.35:1`
**上传尺寸**: 建议 **3840×1632px** 或更大（保持2.35:1）
**格式**: PNG（推荐）、JPG
**文件大小**: ≤10M

**微信在不同场景的显示**：
- 消息列表: 完整显示（自动适配）
- 历史文章: 中央裁切为正方形
- 分享卡片: 裁切适配

**重要**:
- 💡 核心内容放在图片中央区域
- 💡 避免重要信息在边缘（可能被裁切）

---

### 2. 封面图（次条）

**显示比例**: `1:1` (正方形)
**上传尺寸**: 建议 **3072×3072px**
**格式**: PNG、JPG
**文件大小**: ≤10M

---

### 3. 正文插图

#### 横版插图（推荐）

**显示比例**: 约 `1.618:1` (黄金比例)
**上传尺寸**: 建议 **3072×1898px** 或更大
**宽度建议**: ≥2560px（保证清晰度）
**格式**: PNG

#### 正方形插图

**显示比例**: `1:1`
**上传尺寸**: 建议 **3072×3072px**
**格式**: PNG

---

### 4. 内容引导图

**显示比例**: `16:9`
**上传尺寸**: 建议 **3840×2160px**
**格式**: PNG

---

## ⚙️ 微信自动处理机制

### 压缩规则

1. **宽度压缩**
   - 上传 >1080px → 自动压缩到1080px
   - 上传 ≤1080px → 保持原尺寸

2. **格式影响**
   - PNG-24: 压缩损失最小 ✅
   - JPG: 有一定压缩损失
   - GIF: 宽度压缩到640px

3. **像素限制**
   - 单张图片: 长×宽 ≤ 600万像素
   - 超过需要分割上传

## ❌ 常见错误

### 错误1: 预先缩小图片

```python
# ❌ 错误做法
img.thumbnail((900, 383))  # 不要预先缩小！

# ✅ 正确做法
# 保持高分辨率，让微信自动处理
```

### 错误2: 使用低分辨率

```python
# ❌ 错误
width=900
height=383

# ✅ 正确
width=3840
height=1632
```

### 错误3: JPG格式（有损压缩）

```python
# ❌ 错误
img.save("output.jpg", quality=85)

# ✅ 正确
img.save("output.png")  # PNG无损
```
