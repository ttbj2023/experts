# 更新日志

## [未发布]

## [1.0.0] - 2025-02-20

### 新增
- ✨ 微信公众号 Markdown 转换器
  - 基于缩进的智能列表嵌套检测
  - 跨平台字体栈支持（iOS/Android/Windows）
  - LaTeX 公式自动转换为 Unicode 数学符号
  - 移动端优化排版

### 样式优化
- 🎨 粗体文本使用深蓝色 `rgb(15, 76, 129)`
- 🎨 删除线使用浅灰色 `#999999`
- 🎨 章节标题：蓝底白字，带编号
- 🎨 代码块：背景色、圆角、左侧边框

### 列表功能
- 📋 段落模拟列表（避免微信编辑器自动换行）
- 📋 自动检测 Markdown 缩进层级
- 📋 无序列表：`•`（顶级）和 `○`（嵌套）
- 📋 有序列表：自动层级编号（1, 1.1, 1.2）
- 📋 教辅题目格式支持（选择题、步骤题）

### 字体系统
- 🔤 跨平台字体栈：
  - iOS/macOS: San Francisco / 苹方
  - Windows: 微软雅黑
  - Android: 思源黑体 (Noto Sans SC)

### Bug 修复
- 🐛 修复 `analyze_list_indentation()` 函数的 `.lstrip()` 问题
- 🐛 修复列表项之间缺少换行符的问题
- 🐛 修复嵌套列表编号错误（3, 4 → 1.1, 1.2）

### 重构
- ♻️ 将 `convert_demis_style_v2.py` 重命名为 `wechat_markdown_converter.py`
- ♻️ 移除"Demis风格"相关命名
- ♻️ 统一使用常量定义字体和颜色
