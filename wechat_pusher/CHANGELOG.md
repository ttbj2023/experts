# 更新日志

## [2.2.0] - 2026-05-04

### DeepSeek V4 升级
- ✅ **升级到 DeepSeek V4 API**（2026年4月发布）
  - 支持新模型：`deepseek-v4-pro` 和 `deepseek-v4-flash`
  - 旧模型 `deepseek-chat` 和 `deepseek-reasoner` 已弃用
  - 启用思考模式（`thinking` 参数）
  - 思考内容自动隔离，不污染响应内容
  - **智能模型分配**：简单任务（摘要、配图）自动使用 flash 模型，复杂任务使用 pro 模型

### 新增功能
- ✨ **图表生成集成**
  - 集成 chartmaker 项目实现自动图表生成
  - AI 分析图表需求（类型、位置、数据）
  - 支持折线图、柱状图、饼图
  - 自动搜索互联网数据生成精确图表
  - 使用 subprocess 隔离依赖环境

### 优化改进
- 🔧 **优化图片插入逻辑**
  - 修复封面图和第一张插图距离过近的问题
  - 禁止在正文第一个段落之前插入图片占位符
  - 图表生成失败时清理多余空行
  - 移除文章内容中的封面图嵌入（避免重复）

### 配置更新
- ⚙️ **更新环境变量配置**
  - 新增 `DEEPSEEK_MODEL` 配置说明
  - 明确 V4 模型与旧模型的区别
  - 添加思考模式相关配置

### 文档更新
- 📝 **更新 DeepSeek 文档**
  - 重写 `docs/deepseek_workflow.md`
  - 更新模型配置说明
  - 添加思考模式使用指南
  - 更新代码注释，说明新旧模型区别

### 技术细节
- 🔧 **思考模式实现**
  - V4 模型：通过 `extra_body={"thinking": {...}}` 启用
  - 旧模型：通过模型名 `deepseek-reasoner` 识别
  - 响应处理：V4 模型直接返回 content，旧模型提取 `<thinking>` 标签

- ✨ 微信公众号 Markdown 转换器

  - 移动端优化排版

### 样式优化
- 🎨 粗体文本使用深蓝色 `rgb(15, 76, 129)`
- 🎨 删除线使用浅灰色 `#999999`
- 🎨 章节标题：蓝底白字，带编号

- 📋 有序列表：自动层级编号（1, 1.1, 1.2）
