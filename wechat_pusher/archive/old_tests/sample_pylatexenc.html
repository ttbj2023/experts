5. 代码块

5.1 Python 代码

def calculate_variance(data):
    """计算方差"""
    n = len(data)
    mean = sum(data) / n
    variance = sum((x - mean) ** 2 for x in data) / n
    return variance

# 示例使用
data = [4, 8, 6, 5, 3]
result = calculate_variance(data)
print(f"方差: {result}")

5.2 JavaScript 代码

function calculateSum(arr) {
    return arr.reduce((sum, num) => sum + num, 0);
}

// 示例
const numbers = [1, 2, 3, 4, 5];
const total = calculateSum(numbers);
console.log(`总和: ${total}`);

8. 使用说明

转换步骤

  1. 使用转换命令：
    bash ./convert-md-to-html.py sample.md -o output/

  2. 用 Microsoft Word 打开生成的 HTML 文件：
    - 输出路径：output/sample.html

  3. 检查排版、公式、图片是否正常

  4. 文件 → 另存为 → 选择 .docx 格式

  5. 完成！DOCX 文件可直接编辑

支持的特性

  • ✅ HTML 4.01 + CSS 2.1 完全兼容
  • ✅ Base64 内嵌图片（无裂图）
  • ✅ MathJax 公式（可编辑）
  • ✅ 多栏布局
  • ✅ 复杂表格
